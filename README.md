# 健身塑形工作台

面向女生自用健身管理的手机优先工作台。左侧导航固定常驻：手机约 60px 图标栏，桌面约 180px 带文字。

稳定访问地址：

https://uishi2.github.io/xiaochen-fitness-workbench/

## 功能

- 首页：昵称、emoji 头像、连续打卡、训练概览和快捷入口
- 今日任务：默认 6 项，支持新增、编辑、删除、完成和取消
- 计划：一周训练分化与完成标记
- 塑形教程：6 套教程、小红书深链、网页回退和复制链接
- 动作库：腹、臀、肩背、臂、腿分类和动作完成记录
- 计时：秒表、倒计时和训练时长保存
- 训练统计：连续天数、累计天数、总时长、任务/动作数、7 天图表和记录
- 饮食统计：与饮食模块实时联动
- 饮食：早餐、午餐、晚餐、加餐、蛋白及自定义项目
- 设置：昵称、emoji 头像、提醒、JSON 导入导出和清空数据
- 云同步：使用 AES-GCM 加密后同步到 GitHub 仓库，令牌只保留在当前页面内存中

## 云同步

1. 创建一个仅限 `Uishi2/xiaochen-fitness-workbench` 仓库、具有 `Contents: Read and write` 权限的 GitHub 细粒度令牌。
2. 打开工作台右上角“云同步”，输入令牌和至少 8 位同步密码。
3. 选择“上传到云端”或“从云端恢复”。

云端文件位于 `cloud-sync/workbench.enc.json`。文件在上传前完成加密，仓库中不会保存明文健康记录。同步密码无法找回。

## 本地运行

```powershell
npm install
npm run dev
```

手机和电脑连接同一网络后，可使用终端显示的 Network 地址访问。

## 生产预览

```powershell
npm run build
npm run preview
```

## 数据说明

所有数据存浏览器 localStorage，刷新不丢；换设备、清缓存、链接失效会丢失。设置页提供 JSON 备份。
